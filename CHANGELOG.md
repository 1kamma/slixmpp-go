# Changelog

## 0.1.0 — unified port snapshot

- Added RFC 6120/6121 client stream with STARTTLS/direct TLS and SASL.
- Added XEP-0114 component mode.
- Added typed stanzas, mixed-content XML nodes, event bus, matchers, plugin
  manager, scoped APIs, roster, and IQ correlation.
- Added complete Slixmpp 1.17 plugin-name catalog with non-advertising generic
  placeholders.
- Added typed/stateful XEP modules documented in the generated support matrix.
- Added legacy OMEMO XMPP integration, trust/storage contracts, and pluggable
  session backend.
- Added examples, migration/security/architecture documentation, tests, vet,
  and race verification.
